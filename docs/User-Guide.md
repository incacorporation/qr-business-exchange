# QR Business Exchange - User Guide

## Getting Started

### Creating an Account

1. Navigate to the registration page
2. Fill in your details:
   - Email address
   - Secure password
   - First and last name
   - Company name (optional)
   - Phone number (optional)
3. Click "Register"
4. Check your email for verification code
5. Enter the 6-digit code to verify your account

### Logging In

1. Go to the login page
2. Enter your email and password
3. Click "Login"
4. You'll be redirected to your dashboard

## Using the Map Feature

### Enabling "Ping Me"
1. Go to Settings
2. Toggle "Ping Me" switch ON
3. Accept location permissions
4. You'll now appear on the map for others to see

### Finding Nearby Users
1. View the interactive map on your dashboard
2. Use the radius filter (1, 5, 10, 25, 50 miles)
3. Markers show:
   - 🔵 Blue: Free users
   - 🟢 Green: Paid users
   - 🔴 Red: Users with "Ping Me" active

### Viewing User Profiles
1. Double-click any marker on the map
2. Modal displays:
   - Profile picture
   - Name and company
   - Skills
   - Services and pricing
   - Distance from you
   - Rating/reviews

### Making Business Connections

**For Paid Subscribers Only:**
1. Click "Let's Do Business" button in profile modal
2. System checks your credit balance
3. Write optional message
4. Click "Send Request"
5. Request is sent via push notification
6. **If accepted**: 1 credit is deducted
7. **If rejected**: No credit deduction

## Payment & Credits

### Credit System
- 1 credit = 1 connection request
- Credits deducted ONLY when request is accepted
- Credits reset monthly (no rollover)
- Low credit warning at 10% remaining (e.g., 2 credits left for Basic plan)

### Payment Methods
- **PayPal**: Quick checkout
- **Stripe**: Credit/debit cards
- **Clover**: Business payment solution

### Geolocation Verification
**CRITICAL SECURITY FEATURE:**
1. Location captured at payment start
2. Complete payment on gateway
3. Location captured again on return
4. Distance calculated using Haversine formula
5. Payment REJECTED if you moved more than 50 yards
6. Payment APPROVED if within 50 yards
7. Prevents fraud and unauthorized payments

### Payment History
1. Go to Payments page
2. View all transactions
3. See status (Completed/Pending/Failed/Rejected)
4. Download receipts
